✏️ Editor local de configuración

Herramienta para generar el contenido de config.js desde este navegador.

Esto NO es seguridad ni autenticación.
Es una página pública del sitio: cualquiera que la abra puede verla y usarla. No ingreses datos privados. Todo lo publicado en config.js es visible para cualquier visitante.

Sus cambios NO se publican automáticamente. Para que la web cambie hay que reemplazar config.js en el repositorio, hacer commit y push.

Cómo usar: editá los campos → Generar config.js → copiá o descargá → reemplazá el archivo config.js → commit y push → GitHub Pages publica el cambio.
Validación: teléfonos de 8–15 dígitos; códigos de campaña ^[a-z0-9_-]{2,30}$.
